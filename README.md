# Курс RabbitMQ для самостоятельного изучения

Начните с [полного руководства](Методичка_RabbitMQ_для_слушателей.md): шесть модулей, объяснения, лабораторные работы через CLI и UI, ожидаемые результаты, самопроверка и итоговое задание.

- [Программа курса](программа_курса.txt)
- [Готовые файлы практик](practice)
- [Шпаргалка команд](Шпаргалка_команд_RabbitMQ.md)
- [Результаты проверки примеров](practice/ПРОВЕРКА.md)

**Учебная ветка — RabbitMQ 4.1.** Основной стенд запускается через Docker Compose; Python-примеры используют Pika 1.3.2. Подготовка, адреса, пароли и последовательность запуска описаны в руководстве. Полный стенд включает три узла, HAProxy, отдельный брокер и мониторинг; компоненты подключаются по мере прохождения.

**Ключевые мысли и ограничения выделены жирным.** Кодовые блоки предназначены для копирования, а варианты CLI и UI выполняют одну и ту же операцию.
